One weird job title, written by a program. The title reads:

> Professional Mourner for Strangers' Goldfish Funerals

The joke is a real-sounding job — a professional mourner is a genuine profession, hired to grieve at funerals — with one hilariously specific twist: the clients are strangers, and the deceased are their goldfish. You can picture the person in a black suit, solemnly delivering a eulogy over a tiny bowl.

## Run it

```sh
node main.ts
```

It writes the title to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), deterministically, with no trailing newline.
